变成 配音 + 字幕 + 剪映草稿。

BY配音 是一款面向课程 / 批量内容的 AI 配音与字幕生成工具：输入逐字稿，产出配音音频与字幕文件，并可选自动写入本机剪映草稿。

如何使用 ↗ 先看工作流程

选逐字稿.txt 文本，逐行或按段切句

设置样式字体 · 字号 · 描边
开始生成进度条 + 状态栏实时反馈

05 · START

开始使用

便携版，解压即用，无需安装 Python / ffmpeg / 其他命令行依赖。

① 解压并启动

解压 BY配音.zip，双击 启动BY配音.vbs。

② 环境要求

Windows · 已装剪映专业版 · 网络可访问配音接口 · 拥有可用 speaker_id。

字幕和逐字稿不一致怎么办？

改用 strict 严格模式；课程模式会主动去标点、切短句。

自动写入剪映草稿失败？

确认本机已装剪映专业版、草稿目录存在、有写入权限，草稿名不含特殊字符。手动导入 voiceover.ogg + subtitles.srt 也能交付。

扫描不到音色 ID？

先用目标音色再生成一句测试配音，然后重新扫描。

BY配音 · 本地 Windows 便携配音与字幕工具。逐字稿会发送到配音接口生成音频，请勿输入不适合上传的敏感内容；仅使用你本人有权限的音色。依赖第三方软件与接口，接口变化时可能需要更新。
